# ParfumDEPO Telegram Bot

Telegram бот для магазина парфюмерии ParfumDEPO.

## Функции
- 📦 Каталог товаров из Google Sheets
- 🛒 Корзина покупок
- ⚙️ Админ-панель для управления ценами
- 🔗 Интеграция с мини-приложением

## Развертывание на Render
1. Создайте новый Web Service на Render.com
2. Подключите этот репозиторий
3. Добавьте Environment Variables
4. Деплой!

## Environment Variables
- `BOT_TOKEN` - Токен Telegram бота
- `API_URL` - URL Google Apps Script API
- `ADMIN_IDS` - ID админов через запятую
